# Kalika Store - HTML Version Instructions

To get the "pure HTML" version of this website:

1.  **Build the project**: Run `npm run build`.
2.  **Locate the HTML files**: After the build completes, a folder named `dist` will be created.
3.  **Use the content**: The `dist` folder contains the actual `.html`, `.js`, and `.css` files that make up the website.

### Why use React (.tsx files)?
We use React to provide the shopping cart, admin panel, and real-time features. The `.tsx` files are "source code" and they automatically turn into `.html` files when you build the app.

### AdSense
The AdSense code is automatically included in the `<head>` of all pages and in the specific slots you requested (Earn, Shop, Admin, etc.).

### Opening locally
We have configured the project so you can open the `index.html` file inside the `dist` folder directly in any browser.
